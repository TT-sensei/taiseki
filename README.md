# めんせき・たいせきラボ

小学生向け「面積 → 体積」学習ロードマップの単一Webアプリ。

## 構成

```
mensekilab/
├─ index.html          画面全体・4つのStepのHTML
├─ style.css           デザイン（ノート風・図形の色分け）
├─ shapes-data.js      5図形の座標・公式データ
├─ solid-svg.js        3D座標をSVGへ投影する共通立体描画エンジン
├─ step0.js            Step0：図形の変形ギミック（あくしょん公式図鑑）
├─ step1.js            Step1：底面×高さ＝体積（高さ1cmの魔法）
├─ step2-data.js       Step2：複合図形パズルの問題データ
├─ step2.js            Step2：複合図形パズルのロジック
├─ step3-data.js       Step3：レベル別の問題生成・丸めルール
├─ step3.js            Step3：式入力ドリル・計算スキップ・コンボ・にがて復習・学習記録
├─ sound.js            Web Audio APIによる短い効果音と音量設定
└─ main 2.js           画面遷移・公式レスキュー
```

外部ライブラリ・外部フォント・APIなしで動作します。効果音はWeb Audio APIで生成し、設定は端末に保存します。

## GitHub Pagesでの公開手順

1. このフォルダの中身をリポジトリのルート（または `/docs`）にそのまま置く
2. リポジトリの Settings → Pages → Source で対象ブランチ/フォルダを指定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

`index.html` を直接ダブルクリックしてローカルで開くだけでも、外部通信なしで全機能が動作します（fetchを使っていないため、これまでのCORS問題は発生しません）。

## Step構成

- **Step0（こうしきずかん）**: 平行四辺形・三角形・台形・ひし形・円の5図形をタップで変形させ、面積公式を体感する
- **Step1（たかさ1cmの魔法）**: 底面を選び、高さスライダーで1cmずつ積み上げて「底面積×高さ＝体積」を確認する。立体はドラッグで見る向きを変えられ、円を選ぶと角柱の辺の数を増やして円柱に近づけられる
- **Step2（ふくごうパズル）**: L字・穴あき・T字の複合図形を「切り取り線」で分割し、赤／青の色あわせで面積の式を完成させる
- **Step3（たいせきドリル）**: Lv.1「直方体・立方体」、Lv.2「角柱・円柱」、Lv.3「いろいろな底面」のランダム問題。底面の式と高さを入力して、体積を表す式を完成させる。最終の数の計算はしない「計算スキップ」方式。誤答問題を保存し、「にがて復習」で1回正解すると解除する

## 学習サポート

- ヘッダーとドリルにNAVIキャラを配置し、考える・ヒント・再挑戦・正解の場面に合わせて声をかける
- 正解時は短いキラキラ音、見直し時はやさしい確認音。右上の「おと」でオン／オフを切り替えられる
