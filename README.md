# めんせき・たいせきラボ

小学5〜6年生向けの算数学習アプリです。「面積の公式が、体積につながる」を一本の線でたどります。

- 公開ページ: https://tt-sensei.github.io/taiseki/
- 学習の流れ: めんせきの ふくしゅう → たいせき本編（つみあげ・ふくごう・ドリル）→ まちがえた問題の再挑戦 → 学習の記録

## 内容

| 画面 | 内容 |
| --- | --- |
| こうしきずかん（ふくしゅう） | 平行四辺形・三角形・台形・ひし形・円の5図形を変形アニメーションで動かし、面積公式の成り立ちを確かめる |
| つみあげラボ | 底面を選んで高さ1cmの板を積み上げ、「底面積 × 高さ ＝ 体積」を確かめる。立体はドラッグで回転、円は角をふやして円柱に近づける |
| ふくごうパズル | L字型・穴あき・T字型の複合図形を、切り取り線で分けて式を完成させる（面積のふくしゅうと体積の考え方をつなぐ） |
| たいせきドリル | Lv.1 直方体・立方体 / Lv.2 角柱・円柱 / Lv.3 いろいろな底面。底面の式を自分で組み立てて答える。画面内テンキー入力 |
| 再挑戦 | ドリル・パズルで間違えた問題が端末内に記録され、正解すると消える（克服） |
| 学習の記録 | ミッションごとの記録とバッジ（全10種） |

## 計算のルール（ドリル）

- 円周率は 3.14 を使う。
- 底面積は小数第2位まで（四捨五入）。答えの許容誤差は 0.01。
- 生成問題は検算スクリプトで全パターンを再計算して照合している（`verify/` は開発用で公開には含めない）。

## 保存データ

- 保存先: ブラウザの localStorage（キー `taisekiLab.v2`）。外部送信は一切しない。
- 旧バージョンの保存データ（`taiseki-drill-v1`、`taiseki-sound-enabled`）は、初回起動時に新しいキーへ自動で引き継ぎ、旧キーを削除する。

## 技術メモ

- 静的サイト（HTML / CSS / JavaScript のみ）。ビルド不要。
- 演出と音は TT-sensei の共通基盤（edu-effects / sounds-recipe-）、キャラクター画像は navi-character-、バッジ画像は edu-assets を参照する。
- ファイル構成:
  - `index.html` … 画面の土台（単一ページアプリ）
  - `style.css` … デザイン一式（テーマ色は水色）
  - `js/app.js` … 画面遷移・各ミッション・保存・音の制御
  - `js/solid-svg.js` … 立体の描画エンジン（SVG）
  - `js/morph.js` … 面積公式の変形アニメーション
  - `js/data-shapes.js` … 図形と公式のデータ
  - `js/data-puzzle.js` … ふくごうパズルの問題データ
  - `js/data-drill.js` … ドリルの問題生成
