# めんせき・たいせきラボ

小学生向け「面積 → 体積」学習ロードマップの単一Webアプリ。

## 構成

```
mensekilab/
├─ index.html          画面全体・3つのStepのHTML
├─ css/style.css        デザイン（ノート風・図形の色分け）
├─ js/shapes-data.js    5図形の座標・公式データ
├─ js/step0.js          Step0：図形の変形ギミック（あくしょん公式図鑑）
├─ js/step1.js          Step1：底面×高さ＝体積（高さ1cmの魔法）
├─ js/step2-data.js     Step2：複合図形パズルの問題データ
├─ js/step2.js          Step2：複合図形パズルのロジック
└─ js/main.js           画面遷移・公式レスキュー
```

外部ライブラリなし、CDNはGoogle Fontsのみ（オフラインでもフォントが標準にフォールバックするだけで動作します）。

## GitHub Pagesでの公開手順

1. このフォルダの中身をリポジトリのルート（または `/docs`）にそのまま置く
2. リポジトリの Settings → Pages → Source で対象ブランチ/フォルダを指定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

`index.html` を直接ダブルクリックしてローカルで開くだけでも、外部通信なしで全機能が動作します（fetchを使っていないため、これまでのCORS問題は発生しません）。

## Step構成

- **Step0（こうしきずかん）**: 平行四辺形・三角形・台形・ひし形・円の5図形をタップで変形させ、面積公式を体感する
- **Step1（たかさ1cmの魔法）**: 底面を選び、高さスライダーで1cmずつ積み上げて「底面積×高さ＝体積」を確認する。円を選ぶと角柱の辺の数を増やして円柱に近づける操作も可能
- **Step2（ふくごうパズル）**: L字・穴あき・T字の複合図形を「切り取り線」で分割し、赤／青の色あわせで面積の式を完成させる
